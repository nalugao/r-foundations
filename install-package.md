#Instalando
```R
install.packages("nome_do_pacote")
```

#Carregando pacote
```R
library(nome_do_pacote)
```

#Explorando pacotes
```R
help(nome_do_pacote)  # Mostra a documentação do pacote
?nome_da_funcao  # Mostra a documentação de uma função específica

```

#Listando funcoes
```R
ls("package:nome_do_pacote")  # Lista as funções do pacote
objects("package:nome_do_pacote")  # Lista os objetos disponíveis no pacote

```

#atualizanod pacotes
```R
update.packages()
```

#removendo pacotes
```R
remove.packages("nome_do_pacote")
```
